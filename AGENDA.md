# Deadzone MC – Agenda

Ziel: ein fertiges Spiel als Modpack – DayZ + 7 Days to Die + Stalker + Metro + World War Z. Alles muss Sinn
ergeben, immersiv sein, sich lohnen und spielbar bleiben (nichts künstlich Nerviges). Endlos weiterspielbar
nach der Hauptgeschichte (später evtl. DLC). Sprache im Spiel: Deutsch.

Arbeitsweise: Monster-Entwürfe vor dem Einbau zeigen. Nach jeder Etappe spielbare Version (Release-Zip:
https://github.com/Basby1/DeadzoneMC/releases/download/modpack/deadzone-mc-modpack.zip). Fragen stellen, wenn
eine Entscheidung bei Lina liegt. Mods von CurseForge dürfen hinzugefügt werden, wenn passend.

Legende: [x] erledigt · [~] in Arbeit · [ ] offen

## Etappe A – Spielbarkeit (dringend, nach Testspiel 18.10.)
- [x] Spawn-Schutz: Schonfrist nach Spawn/Respawn, Gegner in der Nähe entfernen, kein Spawn-Camping; prüfen, wer schießt
- [x] Startausrüstung: rostiges Messer + Grund-Überlebenspaket
- [x] Tag leichter / weniger Beute – Nacht viel gefährlicher / deutlich bessere Beute
- [x] Beutestufen für Gebäude: Anzeige beim Betreten, höhere Stufe = gefährlicher + bessere Beute, nachts +1
- [x] Blutungs-Debuff entfernen
- [x] Infizierte langsamer (man muss weglaufen können)
- [x] Absturz „Ticking entity“ (Seuchenhund-Rudelruf endlos) behoben
- [x] Leere Truhen: Weltbehälter ohne Beute bekommen beim ersten Öffnen eine Tabelle passend zum Ort
- [x] Wache/Soldat/alle Mobs: Arme und Waffen zeigten nach hinten – gespiegelt (Etappe E teilweise)
- [x] Nachts nicht mehr sofort überrannt: Deckel, Gruppengröße, Pausen zwischen Gruppen, kleinere Herden
- [x] Debuffs raus: Temperatur/Erfrieren (Tough As Nails), Knochenbruch, Aschesturm-Schaden
- [x] Generator-Schutzzone 4× (96 / 160 / 256 Blöcke)
- [x] Keine Phantome, kein Reiten von Monstern, keine Würfe von Monstern
- [x] Alle eigenen Monster etwa gleich häufig, Bosse seltener; Wühler nur in Höhlen

## Etappe D – Geschichte & Fraktionen
- [ ] Hauptgeschichte in 5 Akten (Tagebuch J, Marker), Fortschritt für die Gruppe, unvorhersehbare Plot-Twists,
      immer klar, was als Nächstes zu tun ist
- [ ] Intro-Sequenz beim ersten Betreten mit Spielernamen
- [ ] Fraktionen mit Questreihen, Ansehen, Vorteilen: Banditen, Totenflüsterer (arbeiten mit Infizierten),
      Kinder des Waldes (Baumhäuser), Sandwanderer, Unterwasservolk, Hüter des Himmels (Lategame, schwer erreichbar)
- [ ] Mimik: übernimmt Skin/Name eines Mitspielers, greift schreiend an, wenn man allein ist (Entwurf der Enthüllung zeigen)
